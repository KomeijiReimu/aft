- Agent secret placeholders are now reserved while the vault is unavailable: a bash command or fetched URL spelling `{{ck-secret:...}}` is refused instead of running with the literal text (the agent sees "Secret label {label} could not be resolved: the vault is not available (...). No command was started.", or "Secret placeholder commands cannot run through the host fallback." when the daemon is offline), and `secret.use` calls are refused without filing an approval card. Commands and fetches that spell no placeholder behave exactly as before.
